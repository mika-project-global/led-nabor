# Руководство по обновлению Sitemap

## Автоматическая генерация sitemap.xml

Sitemap генерируется автоматически с помощью скрипта `scripts/generate-sitemap.mjs` и включает:

### Включенные страницы

#### Главные страницы (на RU и EN):
- `/` - Главная страница (приоритет: 1.0)
- `/catalog/` - Каталог товаров (приоритет: 0.9)
- `/blog/` - Блог (приоритет: 0.9)

#### SEO страницы (приоритет: 0.9-0.8):
- `/ceiling-led-lighting/` - Руководство по LED подсветке потолка
- `/led-ceiling-lighting-kit/` - Комплекты LED подсветки
- `/build-your-kit/` - Конструктор комплектов

#### Информационные страницы (приоритет: 0.7):
- `/about/` - О компании
- `/support/` - Поддержка
- `/installation-guide/` - Руководство по установке
- `/business/` - Для бизнеса
- `/faq/` - Часто задаваемые вопросы

#### Юридические страницы (приоритет: 0.5):
- `/privacy-policy/` - Политика конфиденциальности
- `/terms/` - Условия использования

#### Динамический контент:
- Все категории товаров (приоритет: 0.8)
- Все страницы товаров (приоритет: 0.8)
- **Все опубликованные статьи блога из базы данных** (приоритет: 0.7)

## Как обновить sitemap

### 1. Автоматическое обновление (рекомендуется)

Просто запустите команду:

```bash
npm run generate-sitemap
```

Это:
- Подключится к базе данных Supabase
- Загрузит все опубликованные статьи блога
- Сгенерирует sitemap.xml со всеми страницами
- Сохранит файл в `public/sitemap.xml`

### 2. При добавлении новых статей блога

Sitemap **автоматически** включит новые статьи при следующем запуске скрипта. Просто:

1. Опубликуйте статью в админ-панели
2. Запустите `npm run generate-sitemap`
3. Деплойте обновления

### 3. При добавлении новых статических страниц

Отредактируйте `scripts/generate-sitemap.mjs` и добавьте новый URL в раздел статических страниц:

```javascript
LOCALES.forEach(locale => {
  // ... существующие страницы ...
  urls.push(generateUrlEntry(
    `${SITE_URL}/${locale}/new-page/`,
    new Date(),
    'weekly',  // частота обновления
    '0.8'      // приоритет
  ));
});
```

### 4. Пересборка проекта

#### Автоматическая сборка с обновлением sitemap (рекомендуется):

```bash
npm run build:production
```

Эта команда автоматически:
1. Генерирует обновленный sitemap с последними статьями блога
2. Собирает проект
3. Копирует sitemap.xml в папку dist/

#### Ручная сборка:

Если хотите контролировать процесс вручную:

```bash
npm run generate-sitemap
npm run build
```

## Параметры sitemap

### Частота обновления (changefreq):
- `daily` - Главная, каталог, блог
- `weekly` - SEO страницы, категории, товары
- `monthly` - Информационные страницы, статьи блога
- `yearly` - Юридические страницы

### Приоритеты (priority):
- `1.0` - Главная страница
- `0.9` - Каталог, блог, важные SEO страницы
- `0.8` - Категории, товары, конструктор комплектов
- `0.7` - Информационные страницы, статьи блога
- `0.6` - Гарантия
- `0.5` - Юридические страницы

## Проверка sitemap

### Локальная проверка:
```bash
# Подсчет URL
grep -c '<url>' public/sitemap.xml

# Просмотр содержимого
cat public/sitemap.xml
```

### Онлайн валидация:
После деплоя проверьте sitemap на:
- https://www.xml-sitemaps.com/validate-xml-sitemap.html
- Google Search Console → Sitemap
