### 2. ✅ Прогресс-индикатор в sticky-блоке

**Проблема:** Прогресс-индикатор был наверху страницы и терялся при скролле.

**Решение:**

**Desktop:**
- Прогресс перемещен внутрь sticky-панели справа (вверху блока "Итоговая цена")
- Индикатор скроллится вместе с ценами
- Компактный дизайн: "Шаг X из 4" + процент + прогресс-бар
- Мотивационное сообщение после шагов 2-3

**Mobile:**
- Компактный прогресс в collapsed-состоянии bottom bar
- Полный прогресс в expanded-состоянии
- Тонкий прогресс-бар (h-1) для экономии места
- Всегда видим на экране

**Файлы:** `src/pages/BuildYourKit.tsx`

---

### 3. ✅ Автоматический скролл к следующему шагу

**Реализация:**
- После выбора длины (Шаг 1) → плавный скролл к типу света (Шаг 2)
- После выбора типа света → скролл к управлению (Шаг 3)
- После выбора управления → скролл к блоку питания (Шаг 4)
- После выбора блока питания → подсветка кнопки "Добавить в корзину" (pulse + ring-4)

**Детали:**
- Используются refs для каждого шага
- `scrollIntoView` с `behavior: 'smooth'`
- Учитывается fixed header (offset 120px через `scrollMarginTop`)
- Timeout 100ms для плавности
- На mobile кнопка также скроллится в центр экрана

**Файлы:** `src/pages/BuildYourKit.tsx`

### 4. ✅ Централизованные цены и валюта

**Создан конфиг:** `src/config/kit-prices.ts`

**Структура:**
```typescript
KIT_CONFIG = {
  currency: {
    code: 'CZK',      // Валюта (Czech Koruna)
    symbol: 'Kč',     // Символ
    position: 'after' // Позиция символа
  },
  ledStrip: { ... },  // Цены LED-лент
  control: { ... },   // Цены управления
  power: { ... }      // Цены блоков питания
}
```

**Функции:**
- `formatKitPrice(amount, locale)` - форматирование через Intl.NumberFormat
- `calculateKitPrice(...)` - расчет цены комплекта

**Преимущества:**
- Единая точка управления ценами
- Легко изменить валюту (CZK/EUR/RUB)
- Правильное форматирование чисел по локали
- Консистентное отображение везде

## Как изменить валюту

В файле `src/config/kit-prices.ts`:

### Для рублей (RUB):
```typescript
currency: {
  code: 'RUB',
  symbol: '₽',
  position: 'after'
}
```

### Для евро (EUR):
```typescript
currency: {
  code: 'EUR',
  symbol: '€',
  position: 'before'
}
```

Цены нужно пропорционально пересчитать в новую валюту.
