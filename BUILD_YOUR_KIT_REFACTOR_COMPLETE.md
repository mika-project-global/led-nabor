```typescript

Adjustable White → находит продукт id: 2 (Adjustable White)

5м → находит variant с length: 5
10м → находит variant с length: 10
// и т.д.

// Получение цены
const price = product.variants[variantIndex].price;
// Например: RGB+CCT 5м = 5350 CZK

// Добавление в корзину
addToCart(product); // реальный Product объект
```

### 2. **Исправлено добавление в корзину**

**Решение:**
```typescript
// Добавляем РЕАЛЬНЫЙ продукт

// Открываем drawer корзины

  cartButton.click(); // триггерит открытие drawer в Header
}
```

**Нет отдельной страницы /cart:**

## 🔄 Как это работает сейчас

1. **Пользователь заходит на /build-your-kit**
2. **Шаг 1:** Выбирает тип света
   - RGB+CCT (id: 1)
   - Adjustable White (id: 2)
3. **Шаг 2:** Выбирает длину
   - 5м, 10м, 15м, 20м, 25м, 30м
4. **Система:**
   - Находит продукт: `products.find(p => p.id === productId)`
   - Находит вариант: `product.variants.find(v => v.length === length)`
   - Берет цену: `variant.price`
   - Показывает "Что входит в комплект"
5. **Добавление в корзину:**
   - `addToCart(product)` - реальный Product объект
   - Открывается drawer корзины
   - Товар с правильным Stripe ID
