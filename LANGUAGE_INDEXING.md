# Управление индексацией языковых версий

## Описание

Неиспользуемые языковые версии сайта временно закрыты от индексации поисковыми системами с помощью meta-тега `robots`.

## Заблокированные языки

Следующие языковые префиксы закрыты от индексации:

- `/pl/` - Польский
- `/cz/` - Чешский
- `/de/` - Немецкий

## Реализация

Логика реализована в компоненте `src/components/SEO.tsx`:

```typescript
// Определяем неиспользуемые локали
const unusedLocales = ['pl', 'cz', 'de'];
const shouldNoIndex = unusedLocales.includes(locale);

// Условно применяем robots meta-тег
<meta name="robots" content={shouldNoIndex ? "noindex, follow" : "index, follow"} />
```

## Поведение

### Для неиспользуемых языков (pl, cz, de):
- **Meta-тег**: `<meta name="robots" content="noindex, follow">`
- **Эффект**: Страницы не индексируются, но ссылки на них сканируются
- **Применяется ко всем страницам**: `/pl/`, `/pl/catalog`, `/pl/product/*`, `/cz/*`, `/de/*`

### Для активных языков (ru, en):
- **Meta-тег**: `<meta name="robots" content="index, follow">`
- **Эффект**: Нормальная индексация всех страниц

## Как включить индексацию для языка

Когда языковая версия будет готова к индексации:

1. Откройте `src/components/SEO.tsx`
2. Найдите строку:
   ```typescript
   const unusedLocales = ['pl', 'cz', 'de'];
   ```
3. Удалите код языка из массива, например для польского:
   ```typescript
   const unusedLocales = ['cz', 'de'];
   ```
4. Пересоберите проект: `npm run build`

## Проверка

Чтобы проверить, что meta-тег применяется корректно:

1. Запустите dev-сервер: `npm run dev`
2. Откройте страницу с неиспользуемым языком, например: `http://localhost:5173/pl/`
3. Просмотрите исходный код страницы (Ctrl+U)
4. Найдите в `<head>`: `<meta name="robots" content="noindex, follow">`

Для активных языков:
1. Откройте страницу с активным языком, например: `http://localhost:5173/ru/`
2. Просмотрите исходный код страницы
3. Найдите в `<head>`: `<meta name="robots" content="index, follow">`

## Важные замечания

- Директива `noindex, follow` означает:
  - **noindex**: страница не индексируется поисковиками
  - **follow**: ссылки на странице сканируются и учитываются

- Это временная мера до готовности контента на соответствующих языках

- Изменение применяется автоматически ко всем страницам сайта в зависимости от языкового префикса в URL

- После удаления языка из списка `unusedLocales` индексация восстанавливается автоматически
